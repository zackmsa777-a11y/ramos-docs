A practical native language · Simple syntax · Measured speed

Welcome to the Ramos Book

Ramos is a small, self-hosted language that compiles directly to native Linux x64 and Windows x64 executables. Its two guiding rules are simple programming and measured speed.

This book describes Ramos 0.19.0. Markdown chapters are the canonical edition for AI agents, review and offline reading. The HTML edition is generated from those same chapters for comfortable human reading. Historical version labels identify when a feature arrived; they do not change this book's baseline.

Choose your path

  • Building a tool? Read files, libraries and OS libraries and CLI/TUI, then try the projects.
  • Building a desktop window? Read desktop GUI. Windows uses native system controls; Linux GUI requires GTK3 and a display.
  • Writing Ramos with an AI agent? Start with the agent guide and API reference.
  • Working on the compiler? Read self-hosting.

What you can use today

Checked int64 and finite float64 arithmetic, booleans, functions, comments, while/range loops, else-if chains, compound assignment, immutable UTF-8 strings, mutable bytes, structs, typed arrays, reclaiming managed memory, compile-time weave, stdin, streamed files, terminal interfaces and Windows/Linux native GUI controls, directory iteration/creation, lexical path helpers, environment lookup, direct child execution and reusable UTF-8 text builders. Text builders provide immutable snapshots and capacity reuse/release for streamed tools.

Native math adds explicit conversions, square root and fixed decimal formatting. Decimal input adds fallible parsing for numerical CLI apps such as streamed statistics. There are no namespaces, networking APIs or package registry in 0.19.0. Read the OS libraries for directory and child-process contracts. See the new syntax for ranges, else-if chains and compound assignment. See the limits and proposed roadmap. Planned syntax must not be used in programs targeting this version.

Use ramos run app.ramos to compile and execute a source file directly, or build to save an executable. ramos fmt formats a copy or checks formatting. For desktop apps, use ramos run app.ramos --gui; Linux CLI/compiler output remains static. Authoring tools explain arguments, errors and cleanup.
