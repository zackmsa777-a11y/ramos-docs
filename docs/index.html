A practical native language · Simple syntax · Measured speed

Welcome to the Ramos Book

Ramos is a small, self-hosted language that compiles directly to native Linux x64 and Windows x64 executables. Its two guiding rules are simple programming and measured speed.

This book describes Ramos 0.14.0. Markdown chapters are the canonical edition for AI agents, review and offline reading. The HTML edition is generated from those same chapters for comfortable human reading. Historical version labels identify when a feature arrived; they do not change this book's baseline.

Choose your path

  • New to Ramos? Start with install, build and run, then the language and values.
  • Building a tool? Read files, libraries and CLI/TUI, then try the projects.
  • Building a desktop window? Read Windows GUI. The Linux GUI backend is not available in 0.14.
  • Writing Ramos with an AI agent? Start with the agent guide and API reference.
  • Working on the compiler? Read self-hosting.

What you can use today

Checked int64 arithmetic, booleans, functions, comments, while/range loops, else-if chains, compound assignment, immutable UTF-8 strings, mutable bytes, structs, typed arrays, reclaiming managed memory, compile-time weave, stdin, streamed files, terminal interfaces and Windows native GUI controls.

There are no floats, directory iteration, child-process API, namespaces or package registry in 0.14. See the new syntax for ranges, else-if chains and compound assignment. See the limits and proposed roadmap. Planned syntax must not be used in programs targeting this version.

You compile a .ramos source and run the resulting executable. Ramos does not currently interpret a source file or provide ramos run.
