Runnable projects

These are complete programs from Ramos 0.23.0, not pseudocode. The repository includes their exact source under examples/ and the matching stdlib/. Compile commands below assume you placed the native compiler in this repository's root. Add --force when intentionally rebuilding an output.

File copy

./ramos-linux-x86_64 build examples/rcopy.ramos -o rcopy
./rcopy source.bin new-copy.bin

.\ramos.exe build .\examples\rcopy.ramos -o .\rcopy.exe
.\rcopy.exe .\source.bin .\new-copy.bin

Source: rcopy.ramos. Uses streamed I/O, processes files larger than the per-buffer limit and refuses existing destinations. Failed streaming copies can leave a partial new file; they are not atomic replacement.

Literal file search

./ramos-linux-x86_64 build examples/rgrep.ramos -o rgrep
./rgrep needle book/00-welcome.md book/01-getting-started.md

Source: rgrep.ramos. Matches literal bytes, reports file and line, and returns 0 for a match, 1 for none and 2 for errors. It does not traverse directories or interpret regular expressions.

Full-screen file viewer

./ramos-linux-x86_64 build examples/rview.ramos -o rview
./rview book/00-welcome.md

Source: rview.ramos. Run in an interactive terminal; use arrows, j/k, Space/n, p and q. The viewer deliberately sanitizes non-ASCII and control bytes. It is not a complete Unicode text editor.

Desktop Notes — Windows and Linux

.\ramos.exe build .\examples\notes.ramos -o .\notes.exe --gui
.\notes.exe

Source: notes.ramos. Unicode editor, Open/Save/Save As/Clear buttons, status messages and resizing. Save creates a new file and refuses an existing path. Open chooses and loads a valid UTF-8 file; cancellation or invalid text preserves the current note. Save As chooses a new path and keeps exclusive creation. Shared row/padding helpers handle resize. There is no unsaved-change prompt.

A small GUI event loop

Source: gui_hello.ramos:

weave "stdlib/gui.ramos"
weave "stdlib/numbers.ramos"

fn main() {
    gui_check(gui_open(s"Hello, Ramos", 360, 180))
    gui_label(1, 20, 20, 320, 24, s"A real window, written in Ramos")
    gui_button(2, 20, 60, 120, 32, s"Click me")
    var count = 0
    var running = true
    while running {
        let event = gui_event(-1)
        if event.kind == 1 { running = false }
        if event.kind == 2 && event.id == 2 {
            count = count + 1
            gui_set(1, s"Clicks: " + num_text(count))
        }
    }
    gui_check(gui_close())
}

The code above is intended as a root-level source file. The checked-in example is inside examples/ and therefore uses ../stdlib/. Build for Windows with --gui; Linux can run the same source with GTK3 installed:

./ramos-linux-x86_64 run examples/notes.ramos --gui

See desktop GUI setup and limits.

The shell and PowerShell versions of a build follow the same structure: COMPILER build SOURCE -o OUTPUT. Windows outputs should use .exe.

Recursive file-name search

./ramos-linux-x86_64 build examples/rfind.ramos -o rfind
./rfind examples .ramos

Source: rfind.ramos. Iterative traversal uses one directory handle at a time, skips links/junctions and reports OS failures. See limits and traversal policy.

Direct command execution

.\ramos.exe build .\examples\rrun.ramos -o .\rrun.exe
.\rrun.exe .\ramos.exe --version

Source: rrun.ramos. No shell or PATH lookup. Argument values and inherited standard streams are preserved; OS failures are separate from child exit codes. Exit codes above 255 map to 1 in this small CLI wrapper.

Run and format while developing

./ramos-linux-x86_64 run examples/hello.ramos
./ramos-linux-x86_64 run examples/rgrep.ramos -- needle README.md
./ramos-linux-x86_64 fmt examples/hello.ramos -o hello-formatted.ramos
./ramos-linux-x86_64 fmt hello-formatted.ramos --check

The same commands work with .\ramos.exe in PowerShell. Authoring tools cover preserved comments/newlines, error previews and cleanup.

Number UTF-8 lines

./ramos-linux-x86_64 run examples/rnumber.ramos -- input.txt

Source. Streams input, reuses one text builder and normalizes LF/CRLF output. Text builder contracts cover size/error behavior and immutable snapshots.

Render a numerical image

./ramos-linux-x86_64 run examples/mandelbrot.ramos -- image.pgm 320 240 100

.\ramos.exe run .\examples\mandelbrot.ramos -- image.pgm 320 240 100

Source. Native float64 computes P5 grayscale pixels; an image viewer opens the result. Existing output is preserved. Read math and renderer contracts for argument and size limits.

Summarize decimal numbers

./ramos-linux-x86_64 run examples/rstats.ramos -- numbers.txt

.\ramos.exe run .\examples\rstats.ramos -- .\numbers.txt

Source. Read one decimal number per line and report count/min/max/sum/mean. Omit the argument to read stdin. Input files are preserved. Decimal input contracts explain status precedence, strict syntax, fixed output and checked summation.

Larger application: scientific calculator

The calculator repository is a complete application consumer of Ramos 0.24.0: a shared expression engine, CLI/REPL and resizable native desktop GUI. It demonstrates weave, strings, structs, float64, fallible decimal input, reusable functions and GUI event loops. The parser handles precedence, parentheses, integer powers and bounded scientific functions implemented in Ramos. Its README documents numerical limits and setup; its checks compare independent references and native UI behavior.

Find smaller programs in ramos-examples. The existing sources bundled with this book remain pinned and runnable. Browse all five repositories from the Ramos hub.

Larger terminal project: rmatrix

rmatrix is a Ramos port of Rust nmatrix with twelve terminal scenes. It requires 0.20.0 for monotonic timing and demonstrates cached changed-cell drawing, frame deadlines, help/picker overlays and idle pauses. See its build commands, checked platform limits and timing chapter.

Integer file/stdin sorting

./ramos-linux-x86_64 build examples/rsort.ramos -o rsort
printf '3\n-4\n3\n0\n' | ./rsort
./rsort numbers.txt

rsort is a complete native collection example. It sorts signed int64 values with duplicates, handles LF/CRLF and Unicode file paths, and reports malformed input or more than 131072 numbers with a line number and exit 2. See collection status and ownership.

Interactive native plot

plot.ramos draws a curve using the drawing library, changes it with a button and rebuilds its scene on resize. It is verified on both native desktops. Build with ramos build examples/plot.ramos -o plot --gui.

Exact numerical display

math_output.ramos demonstrates compact and scientific output, including tiny values, subnormals and ties-to-even rounding. The calculator uses the same library formatter in its CLI, REPL and desktop GUI.
